## 2. 依据与实现对齐

- 仓库既有 `Store Protocol + InMemory + PostgreSQL + asyncio.to_thread` 结构 → Project、API 文档和 Session 持久层继续采用同一结构。
- FastAPI 官方依赖与异步测试方式 → 路由使用现有 `app.state` 组合，API 测试使用 `httpx.AsyncClient + ASGITransport`。
- Pydantic v2 官方模型机制 → 新写入 DTO 使用字段约束和 `extra="forbid"`；PATCH 使用 `model_dump(exclude_unset=True)` 区分省略与显式 `null`。
- psycopg 参数化与事务规则 → SQL 值统一参数绑定；未引入第二套连接池或数据库驱动。
- `llm-testing-course/线上流量闭环与评测集治理.html`、`评测工程化与CICD.html`、`测试数据合成与用例自动生成.html` → 项目隔离、版本可追溯、失败样本回流和后续用例生命周期规则写入 `AGENTS.md`。
