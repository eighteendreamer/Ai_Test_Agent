# 生产冒烟测试

生产冒烟必须先确认目标、授权、时间窗口、租户、数据边界、停止条件和联系人；默认不做不可逆写操作。发布后检查清单按需读取 `references/source-1.md`。

## 前置契约

必须取得发布版本/变更、目标 URL、只读账号、允许操作、监控联系人、窗口、回滚/停止方式和证据保留策略；任一缺失则暂停执行。

## 工作流程

1. 只选择少量核心链路、健康检查、登录/读取和关键依赖验证。
2. 每个用例声明环境、账号、请求/操作、明确断言、预期耗时和证据。
3. 写操作必须经过额外批准，使用专用测试数据并有清理/回滚方案。
4. 先运行低风险前置，遇到阻断失败立即停止后续用例。
5. 保留请求摘要、响应、截图、日志、时间、版本和清理结果，过滤敏感信息。
6. 将环境故障、产品失败和非阻断观察分开报告。

## 安全门禁

1. 先做健康、登录、读取和关键依赖等低风险检查；前置失败立即停止后续链路。
2. 写操作需要额外授权、专用租户/数据、幂等设计和可验证清理；禁止真实用户数据。
3. 限定请求频率、并发和时长，不进行压力或随机探索。
4. 每项结果绑定版本、时间、环境、账号、请求摘要、响应/截图、日志和清理证明。

## 输出

输出执行授权、用例/断言、实际证据、失败分类、影响、停止动作和后续复查；没有真实证据不得报告生产通过。

## 执行边界

当前系统的生产限制和冒烟确认协议优先于本 Skill；没有真实执行证据时不得报告生产通过。
