# 属性测试

先确认项目语言和已有属性测试库；不要默认安装候选资料中的 fast-check 或其他框架。

## 工作流程

1. 用业务语言定义不变量，例如往返一致性、幂等、单调性、守恒或等价关系。
2. 描述有效与无效输入域、边界分布和前置条件，避免生成器只覆盖常见值。
3. 保留失败 seed、最小反例、运行参数和版本，使失败可重放。
4. 检查过度过滤和无效前置条件，确认测试实际探索了足够输入。
5. 将发现的真实反例固化成清晰的回归用例，再修复根因。
6. 运行仓库已有测试命令并记录次数、seed、缩减过程和退出码。

## 审查重点

- 属性是否只是重复实现被测函数。
- 生成器是否遗漏空值、极值、Unicode、顺序、重复和状态序列。
- 不确定性是否因未记录 seed 而不可复现。

## 输出边界

没有实际框架和执行证据时，只输出属性、生成域和预期反例格式。
