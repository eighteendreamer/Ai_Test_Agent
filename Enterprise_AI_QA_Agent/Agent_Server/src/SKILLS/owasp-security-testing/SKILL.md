# OWASP 安全审查

将 OWASP Top 10 作为静态代码审查分类框架。代码审批阶段只分析代码、配置、依赖和已有测试证据，不执行攻击 payload、扫描器或未授权探测。

## 审查范围

- 访问控制：对象级授权、租户隔离、默认拒绝、权限升级和 IDOR。
- 身份认证：会话、JWT、OAuth、密码、重放、速率限制和错误信息。
- 注入：SQL/NoSQL/命令/模板/LDAP/XSS/SSRF；检查参数化、编码和出口校验。
- 安全设计与配置：CORS、CSRF、Cookie、TLS、调试开关、密钥和安全响应头。
- 数据保护：日志、错误、缓存和 artifact 中的凭据、token、个人信息。
- 依赖供应链：锁文件、来源、版本更新、已知漏洞处理和构建脚本权限。

## 输出纪律

每条发现必须包含信任边界、输入来源、危险汇点、证据位置、影响、修复建议和验证要求。明确区分“静态确认”“需要授权动态验证”和“证据不足”，不得把安全建议写成已完成的攻击结果。

## Top 10 审查导航

- A01 访问控制：身份、租户、资源、动作、默认拒绝、对象级和功能级边界。
- A02 加密失败：传输/存储、密钥生命周期、密码哈希、token 和日志泄露。
- A03 注入：参数化、规范化、查询/命令/模板构造和输出编码。
- A04 不安全设计：威胁模型、业务流程、速率、重放和安全失败默认值。
- A05 配置错误：CORS、CSRF、Cookie、TLS、debug、默认凭据和响应头。
- A06 组件供应链：锁文件、来源、版本、构建脚本和更新策略。
- A07 身份认证：会话、JWT、OAuth、恢复、MFA、过期/撤销和枚举。
- A08 完整性：未验证 artifact、反序列化、插件、CI 下载和签名。
- A09 日志监控：关键事件、上下文、脱敏、告警和保留策略。
- A10 SSRF：目标解析、协议、重定向、内网地址、DNS 重绑定和出口网络。

## 静态工作流

画出外部输入、信任边界、身份上下文、危险汇点和保护措施；用代码、配置、锁文件、测试和日志逐项核对。对每个问题给出最小修复、回归测试和必要的授权动态验证。需要 A01/A03/A07/A10、工具接入或 CI 集成细节时加载 `references/source-1.md`。
