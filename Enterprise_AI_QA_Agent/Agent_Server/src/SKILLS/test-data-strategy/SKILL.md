# 测试数据策略审查

关注数据是否可复现、隔离、最小化且不会泄露真实隐私。只审查仓库中的策略与调用，不在审批阶段连接真实数据库或生成外部数据。

## 审查要点

- 工厂/Builder 是否提供有效默认值，并允许测试显式覆盖关键字段。
- 随机数据是否固定 seed、记录 seed，失败时能重放。
- fixture 作用域是否与隔离要求匹配，测试后是否清理数据库、文件、队列和临时资源。
- 数据是否使用合成值、脱敏值或最小必要字段；日志和 artifact 不得包含凭据或个人隐私。
- 数据关系、唯一约束、时间和时区是否明确，避免依赖执行顺序或共享全局对象。
- 数据播种失败是否可见，部分写入是否回滚或清理。

输出数据生命周期、可复现性、隐私和隔离风险，并给出能直接落地的 fixture/工厂改进建议。
