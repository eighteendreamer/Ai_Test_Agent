# 无障碍测试

自动扫描只能发现部分问题。先确认目标标准、页面状态、浏览器和辅助技术范围，再组合自动与人工证据。

## 工作流程

1. 建立页面、组件、交互状态和关键用户任务清单。
2. 若项目已有 axe/Playwright 无障碍集成，按实际配置运行并保留 rule、节点和影响级别；不要假设依赖存在。
3. 仅使用键盘完成关键任务，检查焦点顺序、可见焦点、陷阱、跳转和弹层焦点恢复。
4. 核对 landmark、heading、name/role/value、表单标签、错误关联和动态状态通知。
5. 检查缩放、重排、颜色对比、非颜色提示、媒体替代和减少动画偏好。
6. 将每个问题关联到页面状态、操作、实际结果、标准条款和证据。

## 执行边界

当前系统没有专用 axe 或屏幕阅读器 Runner 时，只做静态审查、浏览器可达性探索和测试方案；不得声称完成 WCAG 合规认证。

## 输出

区分自动发现、人工复现、需辅助技术复核和无法验证；给出用户影响及修复后的回归步骤。
