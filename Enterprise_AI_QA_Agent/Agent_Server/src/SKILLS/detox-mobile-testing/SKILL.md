# Detox 移动端测试

先读取 React Native、Detox、构建配置、设备配置和项目测试命令；不要假设候选版本或 CLI 参数适用。同步与 device 配置按需读取 `references/source-1.md`。

## 输入契约

确认 RN/Detox 版本、构建 variant、设备、test id、启动参数、账号、数据种子、网络和清理策略。

## 工作流程

1. 将应用构建、测试二进制、设备和系统版本绑定到可复现配置。
2. 为关键元素提供稳定 test id，并核对其不会改变业务语义或可访问性。
3. 利用 Detox 同步机制等待应用空闲；对长期网络、动画或 timer 明确隔离理由。
4. 为每个场景声明启动参数、登录状态、数据种子和清理策略。
5. 覆盖冷启动、后台恢复、权限、离线、错误和导航返回路径。
6. 保存构建日志、设备日志、截图/视频和失败步骤。

## 执行门禁

1. 构建、测试二进制、设备和系统版本绑定到可复现配置。
2. 使用稳定 testID/可访问标识；不得为测试破坏用户可访问语义。
3. 依赖 Detox 同步等待；长期网络、动画或 timer 必须隔离并说明原因。
4. 覆盖冷启动、后台恢复、权限、离线、错误和返回；失败保存构建/设备/步骤证据。

## 输出

输出配置依据、设备矩阵、场景、同步风险、清理策略和缺失能力；无 Runner/设备时只规划。

## 执行边界

当前无 Detox Runner 或设备 Provider 时仅做规划与代码审查，不声称已经构建或执行应用。

## 输出

输出配置依据、设备矩阵、场景、同步风险和缺失条件。
