## 已验证行为

- 读取系统默认生成模板；项目模板写入 MySQL，修改指导和示例后 revision 增加。
- 模板修改不改写已经启用的用例版本，也不改写后续草稿版本。
- JSON 文件导入保留嵌套字段、`false`、`0`、`null` 和中文内容。
- Excel “每行一条用例”和“用例与步骤分表”均完成上传、工作表识别、列映射、预览和提交。
- 原件保存到 RustFS，证据记录文件哈希；原件下载字节与上传字节一致。
- 缺标题、重复编号和业务内容不完整时，预览保留具体诊断；重复编号禁止提交。
- 提交结果进入 PostgreSQL 草稿；评审、启用和创建新草稿版本均保留历史版本与启用指针。
- 相同批次重复提交返回同一 `case_id`，不重复创建。
- 跨项目读取原件和用例返回 404；导入设置按项目隔离，未配置项目使用系统默认。
- API 进程重启后模板、用例和导入批次仍可读取，页面最终 reload 无错误。

## 边界

重启瞬间 Vite 代理记录了 5 个计划内 500（健康、会话和项目摘要请求）。这些请求发生在 API 完成启动前；API 启动日志随后显示对应请求 200，最终页面和持久化断言均通过。后续可单独增加“代理等待后再加载页面”的验收，避免把测试启动竞态混入产品错误统计。

普通需求文档全量 AI 生成、生成任务独立恢复和按用例执行的默认 AI 闭环仍保持未验收状态。
