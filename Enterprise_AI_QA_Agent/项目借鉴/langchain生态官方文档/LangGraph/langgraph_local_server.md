# Run a local server

Copy pageCopy page

Copy pageCopy page

This guide shows you how to run a LangGraph application locally.

## 

​

Prerequisites

Before you begin, ensure you have the following:

  * An API key for [LangSmith](https://docs.langchain.com/oss/python/langgraph/<https:/smith.langchain.com/settings>) \- free to sign up

## 

​

1\. Install the LangGraph CLI

pip

uv
[code]
    # Python >= 3.11 is required.
    pip install -U "langgraph-cli[inmem]"
    
[/code]
[code]
    # Python >= 3.11 is required.
    uv add "langgraph-cli[inmem]"
    
[/code]

## 

​

2\. Create a LangGraph app

Create a new app from the [`new-langgraph-project-python` template](https://docs.langchain.com/oss/python/langgraph/<https:/github.com/langchain-ai/new-langgraph-project>). This template demonstrates a single-node application you can extend with your own logic.
[code] 
    langgraph new path/to/your/app --template new-langgraph-project-python
    
[/code]

**Additional templates** If you use `langgraph new` without specifying a template, you will be presented with an interactive menu that will allow you to choose from a list of available templates.

## 

​

3\. Install dependencies

In the root of your new LangGraph app, install the dependencies in `edit` mode so your local changes are used by the server:

pip

uv
[code]
    cd path/to/your/app
    pip install -e .
    
[/code]
[code]
    cd path/to/your/app
    uv sync
    
[/code]

## 

​

4\. Create a `.env` file

You will find a `.env.example` in the root of your new LangGraph app. Create a `.env` file in the root of your new LangGraph app and copy the contents of the `.env.example` file into it, filling in the necessary API keys:
[code] 
    LANGSMITH_API_KEY=lsv2...
    
[/code]

## 

​

5\. Launch Agent server

Start the LangGraph API server locally:
[code] 
    langgraph dev
    
[/code]

Sample output:
[code] 
    INFO:langgraph_api.cli:
    
            Welcome to
    
    ╦  ┌─┐┌┐┌┌─┐╔═╗┬─┐┌─┐┌─┐┬ ┬
    ║  ├─┤││││ ┬║ ╦├┬┘├─┤├─┘├─┤
    ╩═╝┴ ┴┘└┘└─┘╚═╝┴└─┴ ┴┴  ┴ ┴
    
    - 🚀 API: http://127.0.0.1:2024
    - 🎨 Studio UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
    - 📚 API Docs: http://127.0.0.1:2024/docs
    
    This in-memory server is designed for development and testing.
    For production use, please use LangSmith Deployment.
    
[/code]

The `langgraph dev` command starts Agent Server in an in-memory mode. This mode is suitable for development and testing purposes. For production use, deploy Agent Server with access to a persistent storage backend. For more information, see the [Platform setup overview](https://docs.langchain.com/oss/python/langgraph/</langsmith/platform-setup>).

## 

​

6\. Test your application in Studio

[Studio](https://docs.langchain.com/oss/python/langgraph/</langsmith/studio>) is a specialized UI that you can connect to LangGraph API server to visualize, interact with, and debug your application locally. Test your graph in Studio by visiting the URL provided in the output of the `langgraph dev` command:
[code] 
    >    - LangGraph Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
    
[/code]

For an Agent Server running on a custom host/port, update the `baseUrl` query parameter in the URL. For example, if your server is running on `http://myhost:3000`:
[code] 
    https://smith.langchain.com/studio/?baseUrl=http://myhost:3000
    
[/code]

Safari compatibility

Use the `--tunnel` flag with your command to create a secure tunnel, as Safari has limitations when connecting to localhost servers:
[code]
    langgraph dev --tunnel
    
[/code]

## 

​

7\. Test the API

  * Python SDK (async)

  * Python SDK (sync)

  * Rest API

  1. Install the LangGraph Python SDK:
[code] pip install langgraph-sdk
         
[/code]

  2. Send a message to the assistant (threadless run):
[code] from langgraph_sdk import get_client
         import asyncio
         
         client = get_client(url="http://localhost:2024")
         
         async def main():
             async for chunk in client.runs.stream(
                 None,  # Threadless run
                 "agent", # Name of assistant. Defined in langgraph.json.
                 input={
                 "messages": [{
                     "role": "human",
                     "content": "What is LangGraph?",
                     }],
                 },
             ):
                 print(f"Receiving new event of type: {chunk.event}...")
                 print(chunk.data)
                 print("\n\n")
         
         asyncio.run(main())
         
[/code]

  1. Install the LangGraph Python SDK:
[code] pip install langgraph-sdk
         
[/code]

  2. Send a message to the assistant (threadless run):
[code] from langgraph_sdk import get_sync_client
         
         client = get_sync_client(url="http://localhost:2024")
         
         for chunk in client.runs.stream(
             None,  # Threadless run
             "agent", # Name of assistant. Defined in langgraph.json.
             input={
                 "messages": [{
                     "role": "human",
                     "content": "What is LangGraph?",
                 }],
             },
             stream_mode="messages-tuple",
         ):
             print(f"Receiving new event of type: {chunk.event}...")
             print(chunk.data)
             print("\n\n")
         
[/code]

[code]
    curl -s --request POST \
        --url "http://localhost:2024/runs/stream" \
        --header 'Content-Type: application/json' \
        --data "{
            \"assistant_id\": \"agent\",
            \"input\": {
                \"messages\": [
                    {
                        \"role\": \"human\",
                        \"content\": \"What is LangGraph?\"
                    }
                ]
            },
            \"stream_mode\": \"messages-tuple\"
        }"
    
[/code]
