# Install LangChain

Copy pageCopy page

Copy pageCopy page

To install the LangChain package:

pip

uv
[code]
    pip install -U langchain
    # Requires Python 3.10+
    
[/code]
[code]
    uv add langchain
    # Requires Python 3.10+
    
[/code]

LangChain provides integrations to hundreds of LLMs and thousands of other integrations. These live in independent provider packages.

pip

uv
[code]
    # Installing the OpenAI integration
    pip install -U langchain-openai
    
    # Installing the Anthropic integration
    pip install -U langchain-anthropic
    
[/code]
[code]
    # Installing the OpenAI integration
    uv add langchain-openai
    
    # Installing the Anthropic integration
    uv add langchain-anthropic
    
[/code]

See the [Integrations tab](https://docs.langchain.com/oss/python/langchain/</oss/python/integrations/providers/overview>) for a full list of available integrations.

Now that you have LangChain installed, you can get started by following the [Quickstart guide](https://docs.langchain.com/oss/python/langchain/</oss/python/langchain/quickstart>).

Set up [LangSmith](https://docs.langchain.com/oss/python/langchain/<https:/smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-langchain-install>) tracing to debug your first LangChain app. Follow the [tracing quickstart](https://docs.langchain.com/oss/python/langchain/</langsmith/trace-with-langchain>) to get started. We recommend you also set up [LangSmith Engine](https://docs.langchain.com/oss/python/langchain/</langsmith/engine>) which monitors your traces, detects issues, and proposes fixes.
